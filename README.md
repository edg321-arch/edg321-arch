## How I build
1. **Plan first.** I write out what the tool needs to do and have Claude Code propose a plan, which I review before any code is written.
2. **Build in small steps.** Each change gets reviewed and tested before moving on.
3. **Ship to real users.** Every tool above is used by me or other traders. Their feedback drives the next version.

**Tools I work with:** Claude Code · Cursor · Railway · Kalshi API · speech-to-text APIs · Excel
